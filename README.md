## ▶️ Build
প্রতিটা Part আলাদা Android Studio প্রজেক্ট। যেকোনো Part এর ফোল্ডারে গিয়ে:

    ./gradlew :app:assembleDebug

App খুলে Settings এ নিজের Gemini API key বসাতে হবে।
