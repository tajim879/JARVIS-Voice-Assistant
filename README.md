## 🇬🇧 English

**JARVIS** is a **fully free** Android voice assistant built with Kotlin and Google Gemini Live. This repository is a "playlist" of the project: 7 parts in order, from Part 1 to Part 7.

### ✨ Features
- 🎙️ Real-time voice conversation (Gemini Live), hands-free mode
- 🎭 Personalities: Jarvis Pro, Trina, Girlfriend/Companion, Boyfriend, Professional/Focus
- 🔒 Owner voice lock (offline speaker recognition with Vosk)
- 📱 Phone control: open apps, call contacts by name, send WhatsApp messages, play/search YouTube, open websites
- 🤖 Accessibility automation: taps and types on screen to finish tasks
- 👁️ Screen vision: reads your screen and understands the UI
- 🧠 Memory Core: remembers your preferences, contacts and routines
- 🌦️ Weather and location, Bluetooth headset audio routing, sound effects
- 🎨 Animated orb/HUD, floating avatars, multiple themes, Privacy Shield

### ▶️ Build
Each part is a separate Android Studio project. Requirements: Android 8.0+ (API 26). Go into any part folder and run:

    ./gradlew :app:assembleDebug

### 💸 Is it really free?
- The app is **completely free**: no subscription, no hidden charges.
- The AI runs on Google Gemini, so you need your own **Gemini API key**. You can get one free from Google AI Studio (the free tier has a daily limit).
- Paste the key in the app's Settings. Never share it with anyone.

### ⚠️ Notes
- Accessibility and screen capture are sensitive permissions. Grant them only if you trust the app.
- The release build uses debug signing. Use your own keystore before distributing.
